# Datos de Student Performance — Continuidad en Unidad 3

Esta actividad continúa el proyecto longitudinal iniciado en la Unidad 2 utilizando la cohorte común de **N = 382 estudiantes** que cursan simultáneamente Matemáticas (`student-mat.csv`) y Lengua Portuguesa (`student-por.csv`).

* **Fuente primaria SQLite:** `../02-estadistica-descriptiva/datos/student_performance.db`
* **Respaldo CSV:** `../02-estadistica-descriptiva/datos/student-mat.csv` y `student-por.csv`

El módulo `R/solucion.R` detecta automáticamente la base de datos local o reutiliza la fuente de la Unidad 2 sin duplicar binarios en el repositorio.
