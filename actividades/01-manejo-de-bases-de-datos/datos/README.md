# datos/

Archivos crudos de la actividad. **No se versionan** (ver `.gitignore`).

Para conservar un archivo concreto en el repositorio:

```bash
git add -f actividades/01-manejo-de-bases-de-datos/datos/<archivo>
```

Documenta en el `README.md` de la actividad el origen y la fecha de cada
archivo que uses.
